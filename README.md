# ЗАЛІК

Вебдодаток для тестування курсантів: інструктор створює тест, курсанти складають його за QR-кодом або посиланням, результати й аналітика — в кабінеті інструктора.

Розробник — Юрій Мельничук (позивний «Композитор»). Фаховий аналітик та автор ідеї — Ярослав Дудко (позивний «Ярий»). За ініціативою та підтримкою 158-го навчального центру.
